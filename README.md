# SoulWorker Plugin Launcher

## What the...

This is an auxiliary application designed to inject the loader into the game. It will be useful if you don't have an alternative way to inject the loader.

> I still don't know how it can be automatized, so, I recommend using something alternative.

## How to

- Unpack the latest available archive from the [release](../../releases) page to any desired location.

- Launch **Soulworker_Launcher** with the following arguments:

  - Path to game exe.

  - IP:127.0.0.1

  - PORT:10000

  It will look something like this:

  ```bash
  .\Soulworker_Launcher.exe "A:\SteamLibrary\steamapps\common\Soulworker_KR\Soulworker.exe" IP:127.0.0.1 PORT:10000
  ```

  > If you have steam running, game will connect to official servers.
